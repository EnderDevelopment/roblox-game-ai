# RoblozGame AI

RoblozGame AI is a Roblox script designed to enhance player interaction with game objects. This script enables parts to move when touched by players, creating dynamic and engaging gameplay experiences. It is ideal for developers looking to add simple yet effective interactivity to their Roblox games.

## Install

1. Open Roblox Studio.
2. Create a new script or open an existing one.
3. Copy the contents of `MoveOnTouch.server.lua` into the script.
4. Place the script inside the part you want to move when a player touches it.

## Use

1. Ensure the script is placed inside the part you want to move.
2. Test the game in Roblox Studio to verify that the part moves when a player touches it.
3. Publish your game to make the interactive feature available to players.
